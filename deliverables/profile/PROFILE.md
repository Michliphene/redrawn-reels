# REDRAWN — profile kit (TikTok · Instagram · YouTube Shorts)

## Profile picture
- `avatar_1080.png` (1080×1080, works in the circle crop; tested at 110 px and 56 px) · source `avatar.svg` (regenerate: `node scripts/make-avatar.mjs`).
- Design: navy globe (Natural Earth, public domain) + one gold line "redrawn" across it. Gold = the series' accent colour (chips, dates, captions).

## Name & handle
- **Display name** (searchable on IG/TikTok): `REDRAWN · Map History`
- **Handle**, by preference (check availability; same handle on all 3 platforms): `@redrawn.maps` → `@redrawnmaps` → `@redrawn.history`

## First posts (in order)
EP 1 USSR → EP 2 Alaska → EP 3 Louisiana → EP 4 Korea, then a 5th episode. Post the first 3 within 3–4 days so a new visitor lands on a profile that already looks like a series. Each episode has its own caption, hashtags, covers and pinned comment in `deliverables/<id>/POSTING.md`.
- Instagram grid: use each episode's `cover_3x4.jpg` as the custom cover so the grid reads as a series ("REDRAWN · EP n").
- Pin the strongest-performing reel to the profile after the first week.
